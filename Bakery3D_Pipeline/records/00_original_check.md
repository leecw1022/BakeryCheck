## 이후 단계에서 처리할 사항

1. **크기**: 세 모델 모두 가장 긴 변이 약 1m로 맞춰져 있어 서로의 크기 비율이 실제와 다름 → ① 단계에서 크기 결정 필요
2. **면 수**: 단팥빵이 500,000면으로 다른 두 모델의 10배 → ② 단계에서 모델별로 다른 비율로 줄이기
3. **텍스처 경계에서 갈라진 정점**: 가져오면 텍스처 경계를 따라 정점이 나뉘어 있음(단팥빵 314조각, 롤케이크 242조각, 크루아상 118조각처럼 보임). 시험 결과, 병합 없이 롤케이크를 20%로 줄이면 갈라진 틈(경계 모서리) 6,484개가 생기고, 먼저 병합하면 0개 → 면 수를 줄이기 전에 "Merge by Distance" 필요
4. **텍스처 파일 이름 중복**: 세 파일 모두 텍스처 이름이 `base_color.png`, `normal.png`로 같음 → Unity에서 섞이지 않도록 내보낼 때 이름 구분 필요
5. **재질 값**: Roughness 0.553, Specular 1.0 (Blender로 가져온 값) → ③ 단계에서 광택 확인
6. **캐릭터 움직임**: 뼈대와 애니메이션이 없음 → ⑤ 단계에서 준비
